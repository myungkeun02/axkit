# Android 연결 가이드 (MacroDroid)

ax-kit가 만든 `.macro` 파일 하나를 가져오면 알림·위치·배터리 매크로 3개가 한 번에 설치돼요. 트리거가 파일에 들어 있어서
iOS처럼 자동화를 직접 만들 필요가 없어요. 전체 10~12탭, 5분 안쪽이에요.

준비물: Android 8 이상, MacroDroid 무료 버전. ax-kit가 실행 중인 맥미니.

## 1. MacroDroid 설치 (탭 약 2번)

1. Play 스토어에서 **MacroDroid**를 검색해 설치해요.
2. 처음 열면 안내 화면이 나와요. 가입 없이 쓸 수 있어요.

## 2. 매크로 파일 가져오기 (탭 약 4번)

1. 맥미니 터미널에서 `ax-kit phone pair`를 실행해요. QR 코드와 6자리 코드가 나와요.
2. Android 카메라나 QR 앱으로 QR을 찍어 페이지를 열어요.
3. 페이지에 6자리 코드를 입력하고 `.macro` 파일을 내려받아요. 코드는 10분 동안만 유효해요.
4. 내려받은 파일을 눌러 **MacroDroid로 열기** → **가져오기**를 눌러요.

매크로 3개가 추가돼요.

- `<이름> 알림` — 모든 앱의 알림을 비서에게 전달해요. Android에서는 문자도 알림으로 도착하므로 **SMS 권한 없이** 문자를 읽어요.
- `<이름> 위치` — 30분마다 마지막 위치를 보내요.
- `<이름> 배터리` — 배터리가 20% 아래로 내려가면 한 번 보내요.

무료 버전은 매크로 5개까지 만들 수 있어요. 3개만 쓰므로 2개는 여유예요.

## 3. 권한 허용

필요한 권한은 두 가지예요. 각 권한이 무엇을 하는지 확인하고 허용해요.

### 알림 접근

- 경로: 설정 → 앱 → 특수 접근 → **알림 접근** → MacroDroid → 허용.
- 이유: 알림 제목과 본문을 읽어 문자·택배·카드 승인을 비서에게 전달해요. SMS 권한은 요구하지 않아요.
- 되돌리기: 같은 경로에서 허용을 끄면 돼요.

### 위치와 백그라운드 실행

- 경로: 설정 → 앱 → MacroDroid → 권한 → **위치** → **항상 허용**.
- 이유: 30분마다 위치를 보내고, 도착/출발 판단에 써요.
- 배터리 최적화 예외: 설정 → 앱 → MacroDroid → 배터리 → **제한 없음**. 이걸 끄면 화면이 꺼졌을 때 매크로가 멈출 수 있어요.
- 되돌리기: 위치를 **허용 안 함**으로 바꾸고, 배터리 설정을 **최적화**로 되돌려요.

## 4. 실기기에서 확인하기 (중요)

이 저장소에서는 MacroDroid를 직접 실행할 수 없어서, 내보내기 파일의 세부 필드 이름을 실제 기기에서 확인해야 해요.

1. MacroDroid에서 각 매크로를 열고 **테스트**로 한 번 실행해요.
2. 맥미니에서 `ax-kit doctor`를 실행해 **휴대폰 마지막 신호 시각**이 갱신되는지 봐요.
3. 값이 비어 있거나 매크로가 동작하지 않으면, 알림·위치·배터리 중 무엇이 문제인지 알려 주세요. 파일 형식 정의가 한 곳에
   모여 있어서 한 번만 고치면 돼요.

## 5. 토큰 회전·폐기

- 90일마다 새 파일을 받는 것을 권장해요. `ax-kit phone rotate <기기 id>` → 새 QR로 2번 과정을 다시 해요.
  이전 토큰은 7일 동안만 더 동작해요.
- 휴대폰을 잃어버렸다면 `ax-kit phone revoke <기기 id>`를 바로 실행해요. 그 토큰은 즉시 무효가 돼요.
- 매크로를 지우거나 MacroDroid를 삭제하면 휴대폰에서 토큰도 함께 사라져요.

## 6. 권한·매크로 되돌리기

- 매크로 삭제: MacroDroid → 매크로 목록에서 길게 눌러 삭제해요.
- 알림 접근: 설정 → 앱 → 특수 접근 → 알림 접근 → MacroDroid → 끄기.
- 위치: 설정 → 앱 → MacroDroid → 권한 → 위치 → 허용 안 함.
- 배터리 최적화: 설정 → 앱 → MacroDroid → 배터리 → 최적화.
- MacroDroid를 지우면 매크로와 권한이 함께 정리돼요.

## 참고

- 화면 시간은 Android에서도 1차로 지원하지 않아요. 필요하면 Tasker + Health Connect 같은 별도 도구가 필요해요.
- 알림 매크로는 앱을 가리지 않지만, 민감한 앱의 알림은 MacroDroid 설정에서 제외할 수 있어요.
