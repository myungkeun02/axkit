# 다른 맥의 파일 읽기 (작업용 맥북 연결)

비서는 집에 있는 맥(예: 맥미니)에서 돌아가는데, 실제 일하는 파일과 Claude Code·Codex 대화 기록은 회사 맥북에 있는 경우가 많아요.
이 기능을 켜면 비서가 **맥북의 파일을 읽기만** 해서 "처음 알아보기", 프로젝트 찾기, 파일 이름 찾기에 함께 써요.

- 비서가 있는 맥 = **비서 맥** (맥미니 등)
- 파일이 있는 맥 = **작업 맥** (회사 맥북 등)

## 준비물

1. 두 맥 모두 **Tailscale** 앱을 설치하고 **같은 계정**으로 로그인해 주세요 (https://tailscale.com/download).
   Tailscale은 내 기기끼리만 통하는 암호화된 망이에요. 인터넷에 파일이 공개되지 않아요.
2. 두 맥 모두 켜져 있고 잠자기 상태가 아니어야 해요 (작업 맥이 꺼져 있으면 그때만 건너뛰어요).

## 비서 맥에서 원격으로 한 번에 (추천)

작업 맥에 **원격 로그인**(시스템 설정 › 일반 › 공유 › 원격 로그인)이 켜져 있고 Homebrew가 있으면, 비서 맥에서 한 줄로 끝나요.
작업 맥 앞에 앉을 필요가 없어요. 범위는 기본값(모든 파일 + 대화 기록)이에요.

```
ax-kit remote install --ssh 사용자이름@작업맥주소
```

처음 접속할 때 그 맥의 로그인 비밀번호를 물을 수 있어요(비서 맥의 터미널에서 직접 입력). 처음 파일을 읽을 때 작업 맥 화면에
"문서 폴더에 접근하려고 합니다" 같은 macOS 허락 창이 뜰 수 있어요 — 그때는 그 맥에서 한 번 **허용**을 눌러 주세요.

## 작업 맥에서 (한 번만)

1. 터미널을 열고 ax-kit을 설치해요. 비서 설정은 하지 않아요.

   ```
   비서 맥에서 `ax-kit remote install`을 실행하면 그 맥에 붙여 넣을 한 줄이 나와요 (또는 git clone https://github.com/myungkeun02/axkit.git ~/ax-kit && AX_KIT_NO_SETUP=1 bash ~/ax-kit/install.sh)
   ```

2. 보여 줄 범위를 골라요. 기본은 **모든 파일(홈 폴더 전체)**이에요. 키·비밀번호·.env처럼 보이는 파일과 앱 데이터·캐시
   (~/Library 등)는 그래도 열지 않아요. "폴더만 고르기"를 고르면 폴더를 직접 정할 수 있어요.
   Claude Code·Codex 대화 기록을 보여 줄지도 물어요.

   ```
   ax-kit source setup
   ```

3. 로그인할 때마다 자동으로 켜지게 등록해요.

   ```
   ax-kit source install
   ```

4. 연결 코드를 받아요. **주소**(예: `http://100.64.0.2:7787`)와 **8자리 코드**(예: `ABCD-EFGH`)가 나와요.
   코드는 10분 동안 한 번만 쓸 수 있어요.

   ```
   ax-kit source pair
   ```

## 비서 맥에서

- `ax-kit setup`의 "처음 알아보기" 단계에서 **"일하는 파일은 어디에 있나요?"** 에 "다른 맥" 또는 "둘 다"를 고르고,
  작업 맥이 보여 준 주소와 코드를 입력해요. 연결되면 공유 폴더 수와 대화 기록 수를 보여 줘요.
- 설정이 끝난 뒤에 연결하려면:

  ```
  ax-kit remote add       # 주소와 코드 입력
  ax-kit remote list      # 연결된 맥과 지금 응답하는지
  ```

  연결한 뒤에는 `ax-kit service install`로 비서를 다시 시작하면 반영돼요.

프로젝트 목록에서 `MacBook:~/dev/app`처럼 **이름이 앞에 붙은 것**은 그 맥에 있는 거예요. 이름 없이 `~/…`로 시작하면 비서 맥에 있는 거예요.

## 무엇을 읽고, 무엇을 읽지 않나요

읽는 것 (작업 맥에서 고른 폴더 안만):
- 파일 이름·종류·크기·날짜, 글 문서의 앞부분, Word 등 문서의 글자
- git 저장소의 README·문서·최근 커밋 제목·언어 구성
- 고르면: Claude Code·Codex 대화 (도구 출력은 빼고, 비밀값·이메일·전화번호는 가린 뒤)
- 비서가 "맥북에서 ○○ 파일 찾아줘"라고 하면 Spotlight로 이름만 찾아요

읽지 않는 것:
- 고른 폴더 밖의 모든 파일 (`../`로 빠져나가거나 바로 가기(심볼릭 링크)로 나가는 것도 막아요)
- 키·비밀번호·`.env`·`.ssh`·인증서·여권·통장처럼 보이는 이름
- 너무 큰 파일 (정해진 크기까지만)

그리고:
- **아무것도 바꾸거나 지우지 않아요.** 작업 맥에는 쓰기 기능이 아예 없어요.
- 짝지은 맥(연결 코드를 쓴 맥)만 읽을 수 있어요. 비서 맥은 받은 열쇠를 macOS 키체인에 보관해요.
- 1분에 받을 수 있는 요청 수가 정해져 있고, 잘못된 열쇠나 코드가 계속 오면 잠시 막아요.

## 멈추는 법

- 잠깐 끄기 (작업 맥): `ax-kit source uninstall` — 자동 시작을 멈추고, 더 이상 읽을 수 없어요. 다시 켜려면 `ax-kit source install`.
- 연결 끊기 (작업 맥): `ax-kit source revoke all` — 짝지은 맥의 열쇠를 모두 무효로 해요. 다시 쓰려면 `ax-kit source pair`부터.
- 연결 지우기 (비서 맥): `ax-kit remote remove MacBook` — 목록과 키체인에서 지워요.
- 보여 주는 폴더 바꾸기 (작업 맥): `ax-kit source setup`을 다시 하고 `ax-kit source install`로 다시 시작해요.
- 지금 상태 보기 (작업 맥): `ax-kit source status`

## 잘 안 될 때

- "그 맥에 닿지 않아요": 두 맥이 Tailscale에 로그인돼 있는지, 작업 맥에서 `ax-kit source status`가 "자동 시작: 켜짐"인지 봐 주세요.
- "코드가 맞지 않거나 시간이 지났어요": 작업 맥에서 `ax-kit source pair`로 새 코드를 받아 주세요.
- macOS가 "문서 폴더에 접근하려고 합니다"라고 물으면 허용해 주세요 (안 하면 그 폴더만 건너뛰어요).
- 작업 맥의 기록: `~/.ax-kit-source/logs/source.out.log`
