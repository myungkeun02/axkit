# iPhone 연결 가이드 (iOS 단축어)

ax-kit가 만든 단축어 4개를 iPhone에 넣고, 자동화 3~4개를 직접 만드는 순서예요. 자동화(트리거)는 iOS가 공유를 막아 두어서
사람이 한 번만 만들어야 해요. 전체 15~20분, 탭은 대략 20~30번이에요.

준비물: 맥미니에서 ax-kit가 실행 중이어야 하고, iPhone은 iOS 17 이상을 권장해요. 서명된 단축어를 받으려면 맥미니가
인터넷에 연결되어 있고 iCloud에 로그인되어 있어야 해요.

## 1. 단축어 파일 4개 받기 (탭 약 8번)

1. 맥미니 터미널에서 `ax-kit phone pair`를 실행해요. QR 코드와 6자리 코드가 나와요.
2. iPhone 기본 카메라로 QR을 찍어 페이지를 열어요.
3. 페이지에 터미널의 6자리 코드를 입력해요. 코드는 10분 동안만 유효하고 한 번만 쓸 수 있어요.
4. 파일 4개를 하나씩 내려받아요. 파일을 누르면 단축어 앱이 열리고, **단축어 추가**를 누르면 설치가 끝나요.

파일 이름은 비서 이름에 따라 `<이름> 위치`, `<이름> 문자`, `<이름> 걸음`, `<이름> 메모`예요.

> 서명이 실패하면 `ax-kit phone pair`가 그 자리에서 순서대로 안내해요. 먼저 맥미니의 iCloud 로그인과 인터넷 연결을
> 확인하고 `ax-kit phone pair`를 다시 실행해요. 그래도 안 되면 아래 iCloud 링크 방식을 써요. 서명 안 된 파일은
> iOS가 바로 가져오지 못해요.

### 1.1 서명이 안 될 때 — iCloud 링크

단축어 파일을 서명하는 `shortcuts sign`은 iCloud 로그인과 인터넷이 필요해요. 서명이 안 되면 ax-kit는 파일 대신
**연결 문자열**(`<수집 주소>|<토큰>`)을 페어링 페이지에 준비해요. 이 방식은 주소나 토큰이 들어 있지 않은 "범용"
템플릿을 한 번 만들어 두고, 설치할 때 연결 문자열만 붙여 넣는 방법이에요.

1. 서명할 수 있는 Mac에서 범용 템플릿 4개를 만들어요.
   ```bash
   ax-kit phone template --out ~/ax-kit-templates
   ```
2. 그 Mac의 단축어 앱에서 템플릿을 열어 **단축어 추가**를 누르고, 공유 → **iCloud 링크 복사**로 링크를 얻어요.
   (파일을 열어 추가하기 어렵다면 `shortcuts sign`으로 서명한 뒤 공유해도 돼요.)
3. 링크 4개를 `~/.ax-kit/config.json`의 `plugins["bridge.mobile"].icloudLinks`에 종류별로 넣어요.
   ```json
   {
     "plugins": {
       "bridge.mobile": {
         "enabled": true,
         "icloudLinks": {
           "location": "https://www.icloud.com/shortcuts/…",
           "sms": "https://www.icloud.com/shortcuts/…",
           "steps": "https://www.icloud.com/shortcuts/…",
           "voice_memo": "https://www.icloud.com/shortcuts/…"
         }
       }
     }
   }
   ```
4. 다시 `ax-kit phone pair`를 실행해요. 서명이 실패하면 터미널이 위 링크들을 순서대로 보여 줘요.
5. iPhone에서 각 링크를 열고 **단축어 추가**를 누른 뒤, 물어보는 연결 문자열을 붙여 넣어요. 연결 문자열은
   터미널이 아니라 **휴대폰 연결 페이지에서 6자리 코드를 넣은 뒤**에 보여요. 그 화면을 닫으면 다시 볼 수 없어요.

`icloudLinks`는 `https://www.icloud.com/shortcuts/`로 시작하는 링크만 사용해요. 다른 주소는 무시해요.

## 2. 자동화 만들기 (권장 3개, 자동화당 탭 약 6번)

단축어 앱 → **자동화** 탭 → **+** → 트리거를 고르고 **즉시 실행**을 켠 뒤, 동작으로 **단축어 실행**을 추가해요.

### 2.1 문자 → `<이름> 문자`

- 트리거: **메시지(문자)**
- 조건: 필요한 발신자나 낱말만 골라도 돼요. 비워 두면 모든 문자를 보내요.
- **즉시 실행**을 켜요. (꺼 두면 확인 버튼이 떠서 자동 전달이 안 돼요.)
- 동작: **단축어 실행** → `<이름> 문자`를 골라요. 입력은 자동화가 넘겨주는 메시지 그대로 두면 돼요.
- 용도: 카드 승인·택배·예약 문자를 비서가 읽어요. 인증번호는 10분만 메모리에 보관하고 채팅에는 보이지 않아요.

### 2.2 도착/출발 또는 시간 → `<이름> 위치`

- 트리거: **도착** 또는 **출발**에서 집·회사를 지정하거나, **특정 시간**(아침 8시, 저녁 8시)을 골라요.
- **즉시 실행**을 켜고 동작 **단축어 실행** → `<이름> 위치`를 골라요.
- 위치 권한: 처음 실행할 때 묻는 **허용**을 누르면 돼요. 백그라운드 자동 실행에는 **항상 허용**이 필요할 수 있어요.

### 2.3 밤 9시 → `<이름> 걸음`

- 트리거: **시간** → 매일 **오후 9시**.
- 동작 1: 건강 앱의 **샘플 찾기** → 유형 **걸음**, 기간 **오늘**.
- 동작 2: **통계** → **합계**.
- 동작 3: **단축어 실행** → `<이름> 걸음`, 입력은 앞 단계의 합계로 지정해요.
- 처음 실행할 때 건강 데이터 **읽기** 권한을 물어요. 읽기만 허용하면 돼요.

### 2.4 음성 메모 → `<이름> 메모` (자동화 아님)

- 설정 → Siri 및 검색에서 `<이름> 메모`를 실행하는 음성 명령을 추가하거나, 동작 버튼에 단축어를 연결해요.
- 실행하면 받아쓰기 → 전송 → "보냈어요" 알림 순서로 동작해요.

## 3. iOS가 읽을 수 없는 것

- **화면 시간(스크린 타임)**: 단축어로 읽는 방법이 없어요.
- **다른 앱의 알림**: iOS는 다른 앱 알림을 단축어에 넘겨주지 않아요. 앱 알림이 필요하면 Android 가이드를 봐요.
- 사진·음성 메모·링크는 디스코드 공유 시트로 보내는 쪽이 간단해요. 모바일 브리지는 자동으로 흘러오는 신호 전용이에요.

## 4. 토큰 회전·폐기

- 90일마다 새 파일을 받는 것을 권장해요. `ax-kit phone rotate <기기 id>` → 새 QR로 1번 과정을 다시 해요.
  이전 토큰은 7일 동안만 더 동작하고 그 뒤에는 거절돼요.
- 휴대폰을 잃어버렸다면 `ax-kit phone revoke <기기 id>`를 바로 실행해요. 그 토큰은 즉시 무효가 돼요.
- 기기를 지우거나 단축어를 삭제하면 휴대폰에서 토큰도 함께 사라져요.

## 5. 권한 되돌리기

- 단축어 삭제: 단축어 앱에서 해당 단축어를 왼쪽으로 밀어 삭제해요.
- 자동화 끄기: 단축어 앱 → 자동화 → 해당 자동화를 끄거나 삭제해요.
- 위치: 설정 → 개인정보 보호 및 보안 → 위치 서비스 → 단축어 → **안 함**.
- 건강: 설정 → 건강 → 데이터 접근 및 기기 → 앱 → 단축어 → 접근을 끄거나 삭제해요.
- iCloud 링크로 설치했다면 링크를 공유 해제해요.
